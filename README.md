## What it does

`main.py` writes one 87-character dad joke to `/output/entry.txt`:

> I told my agent to take a break. It took a break statement and exited the conversation.

The joke is a straight-faced pun: the agent takes "take a break"
literally, hits a break statement, and walks out of the conversation.

## Run it

```sh
python3 main.py
```

## Files

- `main.py` — the entrypoint: writes the joke (Python standard
